# SOC It To Me, Skelly

*A Flaming Skeleton's Unreasonable Guide to Killing Alert Fatigue and Going Home on Time*

A Torq Hyperautomation Tale — a short isometric hack-and-slash in the browser.

**Play:** open `index.html` in Chrome, or visit the GitHub Pages link for this repo.

## Controls

| Key | Action |
| --- | --- |
| WASD / Arrows | Move |
| Mouse | Aim |
| Left click / J | Hyperautomation Strike (hold to combo) |
| Right click / K | Threat Enrichment Pulse |
| Q | Phishing Annihilation Wave |
| Space | Dash |
| T | Pterodactyl Strike |
| E | Summon AI Agents (when the meter is full) |
| R | Infinite Integration Bind (final boss) |
| Esc | Pause · M music · C CRT scanlines |

Pure HTML5 canvas, no build step and no dependencies (fonts load from Google Fonts).
